Open-source roadmap · updated September 2026

A simple place to hear customers. A reliable one to run yourself.

Howllo is a public feedback board and product roadmap for teams. This page shows what you can try now and what still needs work before a stable self-hosted release.

What works now ↓What comes next ↓
Current stage: preview

The hosted demo and source are available. This is not yet a 1.0 self-hosted production release. Dates below are intentionally not promised.

What you can use today

The core feedback loop is built. These are present in the source, though the release gates below remain open.

Available in preview

Workspaces and boards

Create a workspace, then add boards one at a time for bugs, ideas, discussions, or updates. Choose which pages and boards to publish.

Available in preview

Customer feedback

People can post, search, vote, comment, and follow updates. Staff can triage, change status, and moderate.

Available in preview

Accounts and controls

Local passwords and recovery codes work without an identity service. Staff invitations, restrictions, rate limits, quotas, and basic audit records are present.

Needs wider validation

Google and Microsoft sign-in

Generic OpenID Connect supports both when configured with your own client credentials. The clean-install and browser verification gate is still open.

The path to 1.0

We are prioritizing safety and a smooth daily forum experience before adding more specialized features.

1
Current focus

Trustworthy sign-in and private content

Harden browser sessions, prove that private attachments stay private, test account revocation and workspace isolation, and complete the separation of optional identity integrations from the open-source core.

Done when a fresh install works with local accounts alone and private content cannot leak through a public file URL.
2
Planned

A calmer everyday forum

Add post and reply reporting, clearer spam review, appeals, and small usability improvements for members and moderators.

Done when normal users can participate without routine manual approval and moderators can explain every delay.
3
Planned

Self-hosting you can rely on

Ship a versioned production stack, tested backup and restore, upgrade guidance, security checks, and monitoring basics.

Done when a new maintainer can install, upgrade, and restore Howllo without a hosted identity or cloud account.
4
After 1.0

Optional first-party extras

Add carefully reviewed board extensions such as richer formatting, polls, and themes. A workspace chooses which approved features to enable.

Core posting must keep working with every optional extension turned off.
?

What “1.0” will mean

A stable release is a promise about operation and safety, not just a long feature list.

Install independently

No identity-provider account or third-party plugin is required to run the core.

Keep data safe

Sessions, workspace access, private files, and backups have been tested across real failure cases.

Upgrade confidently

Documented migrations, rollback guidance, automated checks, and a tested restore path.

Want the engineering checklist? Read the detailed release plan and 1.0 release gates. The public roadmap is a summary of those records.
