# Contributing

Bug reports, documentation and core code fixes are welcome. Start with an
issue describing the behavior and a way to reproduce it. Keep pull requests
focused, add a test when a permission or security boundary changes, and run
the checks in [CI](.github/workflows/ci.yml) before submitting.

Plugins are first-party only: the Howllo maintainer writes and ships every
plugin. Please suggest plugin ideas through issues; do not submit plugin code,
remote assets or tenant-executable scripts. Workspace and board owners choose
which approved built-in plugins to enable.

For local development, follow the [README](README.md). For security reports,
use the private channel in [SECURITY.md](SECURITY.md).
