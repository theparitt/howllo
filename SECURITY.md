# Security policy

Howllo is a preview release. It does not yet meet the production release gates
in [the roadmap](docs/roadmap.md), particularly for browser sessions and
private media. Do not use private boards for sensitive data until those gates
are complete.

Report a vulnerability through [GitHub's private vulnerability reporting](https://github.com/theparitt/howllo/security/advisories/new).
Include the affected version or commit, a minimal reproduction, the expected
and actual behavior, and your assessment of impact. Do not put exploit details
or credentials in a public issue.

The maintainer will triage the report privately, coordinate a fix and publish
an advisory when appropriate. No fixed response-time guarantee is offered for
this preview release.
