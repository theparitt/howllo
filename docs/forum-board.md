# Forum board basics

Each workspace can have several boards. A board contains topics and replies.
Visitors see a familiar topic list, search, categories, tags and pagination.
The board type changes the posting language and status display: discussions,
feature requests, bug reports or announcements.

## Staff controls

In the staff app, open **Boards**, select a board, and use:

- **Board appearance and plugins** to set a short announcement, sidebar notes,
  footer note, and approved plugins for that board.
- **Topics and pinned posts** to search visible topics and pin or unpin one.
- Existing board settings for name, intro, image, color, voting, replies,
  categories, tags, publication and privacy.

The public board has **Latest**, **Hot** and **Top** views. Latest places pinned
topics first, then orders by creation date. Hot puts topics from the past seven
days first and ranks each group by two points per vote plus one per visible
reply. Top orders by vote count. Search and category/tag filters work with
these views.

Announcements, sidebar text and footer text are plain text. They cannot inject
HTML, JavaScript or external styles into visitor pages. The board header image,
background image and board icon remain regular settings. Special presentation
styles are approved by the platform admin and enabled per board.
